# Troubleshooting (every failure seen while building this workflow)

| Symptom | Cause | Fix |
| --- | --- | --- |
| `npx hyperframes` errors / engines | HyperFrames CLI needs Node ≥ 22 | `brew install node@22`; `setup_env.sh` puts it first on PATH in `env.sh` |
| `init` writes into `~/.claude/skills` | init refreshes global skills | `HYPERFRAMES_SKIP_SKILLS=1` (set by `env.sh`); skills come from the pinned workspace checkout |
| `fetch-pr: gh pr view "owner/repo#N" failed … not a git repository` | gh can't resolve `owner/repo#N` outside a checkout | pass the full PR URL |
| edge-tts `WSServerHandshakeError: 403` | Oct 2026: legacy `speech.platform.bing.com` refuses synthesis | `edge_tts_engine.py` points `WSS_URL` at `api.msedgeservices.com` (rany2/edge-tts#491); `EDGE_TTS_LEGACY_HOST=1` to disable once upstream ships the fix |
| Voice says 下划线 / 井号 / 乘 / 正 5% | `_`, `#`, `×`, `+` reached edge-tts | `pronounce.py` rewrites them (identifier rule, `patterns`); check the engine log's `· X→Y` list |
| An English term is misread ("Flesh and Fur", "Deep Seat", "Mouse") | Xiaoxiao blurs run-together / rare words | `pron_check.py --asr` → add the respelling it suggests to `pronunciation.json` (`references/pronunciation.md`) |
| `<phoneme>` / `<sub>` / `<break>` in the text → `NoAudioReceived` | the free Edge endpoint rejects inline SSML | respell in `pronunciation.json` instead |
| Kokoro Chinese sounds robotic | HyperFrames' offline Kokoro phonemizes Chinese via espeak | use the edge-tts engine (`HF_MEDIA_ENGINE`) — default in `env.sh` |
| 乱码 (random glyphs) in Studio, fine in snapshots | frames declared `@font-face{src:local("PingFang SC")}`; the .ttc picks the wrong face | bundle Noto SC subsets (`subset_fonts.py`); `check_frames.mjs` rejects `local()`/PingFang/Songti |
| `font_family_without_font_face` lint error | a CJK family is used without `@font-face` | declare the bundled Noto faces with `url("assets/fonts/…-Subset.woff2")` |
| A character renders in a fallback face | subset made before the text changed | re-run `subset_fonts.py` after every text edit (it fails if a used CJK glyph is missing) |
| `assemble-index: frame contract: composition id is missing on the template root` | worker put `<style>` before the root div | root div first inside `<template>`, styles/scripts inside it; re-dispatch with the finding |
| `frame packet is N bytes (limit 48000)` | blueprint body + cited rule recipes too large | drop one cited rule id from that frame's Scenes, or use `blueprint: compose` |
| 150+ `id_requires_css_escape` warnings | ids like `01-hook-num` start with a digit | harmless (workers use `getElementById`); new dispatches prefix ids with a letter |
| Captions: spaces between every Chinese word | captions.mjs joined words with `" "` | the CJK patch (`patches/…`) joins without spaces and keeps one gap at Latin seams |
| Captions: `FP 32`, `FLUX. / 2`, `torch. / equal` | edge-tts splits terms; `.` ended the group | engine `merge_split_terms` re-joins ASCII terms with no whitespace (or only `._-/`) between them |
| Captions flash 1-word groups in enumerations | TTS pauses after 、 triggered the silence split | patch: 、 is not a split, an overflow breaks after the last 、 |
| `retime_frames.py` skips a frame / maps the wrong frame | registration written `=tl;` without spaces; extra frames like `19b-*.html` | fixed: the regex allows any spacing and frames map through STORYBOARD.md `- src:` |
| Re-voicing a project that was retimed before scrambles its cues | its WARP maps an intermediate take, and the built take is gone | `retime_frames.py --chain` (revoice.sh does it when `audio_meta.built.json` is missing) |
| Re-running TTS shifts everything by 0.1–1 s | edge-tts takes are not bit-identical | keep `audio_meta.built.json`; `retime_frames.py` re-maps frames to the new take |
| Closing frame feels rushed | last line ends abruptly | engine pads the last line with `EDGE_TTS_PAD_LAST` (2 s) |
| `check` contrast warning on separators | `·` separators too faint during a crossfade | darken to `rgb(137,134,128)` |
| Headless Chrome screenshot never exits (macOS) | Chrome keeps running after writing the PNG | `make_cover.py` polls for a stable file and kills the process group |
| Cover PNG shows boxes | `make_cover.py --png` couldn't find the Noto TTFs | run `setup_env.sh` (downloads them to `$SEV_WS/fonts`) |
| Studio preview tiny / can't verify glyphs | Browser pane resolution | verify on contact sheets of the rendered MP4 (`qa_sheet.sh`) |
| ✱ / ✓ / ✗ show as tofu or a fallback face | not in EB Garamond / Inter / JetBrains Mono / Noto SC | draw them as inline SVG (workers do this), or accept the system symbol fallback on the render host |
| Bilibili cover: 4:3 crop cuts the badge, or 16:9 crop cuts logo/badge | Bilibili keeps one image and crops it to 4:3 + centred 16:9; per-ratio uploads don't stick | upload the 1440×1080 cover from `make_cover.py --png-bili` with 「双比例同步改动」 on |
| A caption group ends inside a term, e.g. `FastWan2.` then `2 只跑 3 步，` | edge-tts tokenizes a number + Chinese classifier (只 / 个 / 张 / 帧 / 步) as one word (`2 只`), so `merge_split_terms` can't re-join `FastWan2.2` and `attach_punct` treats the `.` as a sentence end | put a comma or another word right after the term in the narration (`FastWan2.2，只跑 3 步`) and re-TTS that line; scan `caption_groups.json` for groups that end in `.` after a letter or digit, as well as groups with no punctuation at all |
| A dotted version splits the caption: `v0.` then `5.18 里，` | edge-tts returns `5.18 里` as one word (the Chinese character sticks to the number, as with classifiers), so `merge_split_terms` cannot re-join `v0.5.18` | end the version with punctuation in the narration (`当时用的是 v0.5.18，每个请求…`) and re-TTS that line; the WordBoundary output then carries `v0.5.18，` as one word (PR 37909 video, 2026-10-24) |
| `pron_check.py --asr` dies with `ImportError: Using SOCKS proxy, but the 'socksio' package is not installed` | a SOCKS `all_proxy` in the shell makes huggingface_hub build a SOCKS client while mlx-whisper looks up the cached model | run it as `env -u all_proxy -u ALL_PROXY HF_HUB_OFFLINE=1 $SEV_PY -I …/pron_check.py …` (the model is already cached); do the same for `retts.py`-style subset TTS calls if they fail the same way |
| One line is re-voiced after its frame was already built, while other frames were built on the newer take | a whole-project `retime_frames.py --ref-meta <old take>` would also warp the frames built on the newer take | snapshot `audio_meta.built.json` before the re-TTS, then retime only that frame: `retime_frames.py --project $P --ref-meta <snapshot> --frames <fid>=<frame N>` (PR 37909 video, 2026-10-24) |
| `assemble-index` warns the total lands N% over the brief's expectation | the brief's `length` is only an estimate | expected when the material needs it — update `length:` in BRIEF/STORYBOARD; never trim content to hit it |
| `code-typing` block missing in the project | `hf add` was skipped or ran outside `$P` | run `(cd $P && hf add code-typing)` before packets, or let the worker inline an adapted typing engine |
| Captions show `两个-a` / `用@flow` with no gap | `LATIN_EDGE` in the captions patch treated `-` and `@` as CJK-side characters | patch now includes `@` and `-` in `LATIN_EDGE`; rebuild captions (and update any caption-translations keys that changed) |
| Captions show `f 选 flow` for a spoken CLI flag `-f` | Edge's WordBoundary drops a leading `-` the way it drops a leading `/` | before captions/build, prefix the word text with `-` in `audio_meta.json`, `audio_meta.built.json` and `audio_engine_meta.json` (the audio is unchanged), or say 杠 f |
| `pron_check.py --asr`: `ImportError: Using SOCKS proxy, but the 'socksio' package is not installed` | an `all_proxy=socks5://…` in the shell makes huggingface_hub build a SOCKS client even for the cached Whisper model | run it as `env -u all_proxy -u ALL_PROXY HF_HUB_OFFLINE=1 $SEV_PY -I …/pron_check.py …` (keep the http proxies: Edge still needs them) |
