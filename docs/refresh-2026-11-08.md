# November 2026 refresh: evidence scope

The [source contracts](upstream-source-contracts.md) freeze November 8 main
heads for SGLang, vLLM, TensorRT-LLM, TokenSpeed and FlashInfer. This refresh
compares the relevant October contracts with current callers, implementations,
HTTP schemas and log emitters. It does not claim a complete review of every
intervening upstream commit or redate the model PR dossiers.

## Behavioral fixes

- vLLM capture negotiates per-session prefix and iteration overrides through
  the deployed OpenAPI schema. Bodyless control remains compatible with old
  or OpenAPI-disabled servers; launch warmup/schedule settings still apply.
- SGLang staged capture returns one invocation's directory rather than a root
  containing previous prefill/decode runs. Current Rust ingress is accepted;
  opt-in profiler v2 remains rejected because its protocol differs.
- Capacity analysis sums a post-capture target with its DFlash-family draft
  backing owners per rank. A later target summary starts a new resize round.
  Independent pools and recurrent state are retained, while VA reservations
  are not counted as physical memory.

Architecture-diagram assets, recent explainer-video implementation and pinned
model-config provenance are not redated: no source-dependent defect was found
in those surfaces in this audit. Historical GPU tables, bilingual PR cards
and cookbook support labels retain their original evidence dates. The current
source guide supersedes historical catalog rows where dispatch has changed.

## Cleanup

Removed the unused `analyze_sglang_torch_profile.py` forwarding wrapper; use
`analyze_llm_torch_profile.py --framework sglang`. Removed five tests that only
mirrored model-profile constants, one that froze a model-name list and one
that searched documents for retired flag words. Kept classification, malformed
input, payload, isolation, memory arithmetic, rendering, packaging and evidence
provenance tests. The compiler guide drops removed pass rows and a duplicate
base-class pointer row rather than preserving them as current advice.

## Validation and limits

Validation: 266 CPU tests and 233 subtests passed (one optional test skipped),
51 cookbook configs passed, and all 11 skill entrypoints passed frontmatter
validation. Pre-commit and offline Lychee checks passed. All 45 current
immutable source links resolve in the frozen upstream trees; additional local
doc links were checked. The pinned `deepseek-v4.1-flash` compute CLI also
produced valid JSON for TP4, six query rows and an 8192-token prefix.
These are analytical shapes, not a measured serving result.

New regressions cover modern/legacy vLLM
payloads, Rust SGLang control, stale stage artifacts and interleaved target/draft
resize rounds. No GPU capture, kernel benchmark or model-accuracy rerun was
performed. External TokenSpeed SMG HTTP forwarding still requires checking the
installed wheel. Source eligibility and CPU tests do not establish a speedup,
numerical equivalence or a deployed backend's support.
